衡枢 HENGSHU · 多机推理 LB 架构 v1.6

定稿 · SSH 纳管 · 仪表盘 · N 节点一主多备 VIP · 控制台无状态全节点 · 会话保持 · Web 终端 · 服务远程启停 · 多机并行单模型 · 规则路由 · 多租户隔离 · REST API + Webhook · 离线交付

SSH 纳管 · 一次性 bootstrap

  • • 控制台填 IP+账密 → asyncssh 连接，指纹确认后信任
  • • 自动采集画像：GPU/OS/Docker/磁盘
  • • 一键推送：节点 token → SFTP 上传 → 远程安装 → 反向注册
  • • 运行期走 Agent 通道；SSH 留作应急

接入层高可用（VIP :9000）

  • • 所有节点跑 Router，一主多备，VRRP 心跳互检
  • • VIP 漂移 advert 1s / master_down 3s，中断 3–5s
  • • 备机热备连同一 Redis，接管即服务、会话不丢
  • • 防脑裂：VRRP 同组 + Redis 选主锁

管理面高可用（VIP :8080）★ v1.2

  • • 控制台无状态：凭证/配置/审计/任务进度全存 Redis
  • • 全节点部署，keepalived 管理 VIP :8080 漂移
  • • kill 任一节点 → 控制台固定 URL 照常用，凭证可解密
  • • 主密钥=部署时环境变量（不依赖机器指纹）
  • • Redis 主从+哨兵，sentinel 30s 自动切换

平台管理 ★ v1.3

  • • admin 登录：argon2 哈希、会话 TTL 8h、登录限流审计
  • • 模型服务远程启停：自定义 start_cmd（vllm serve/docker run/systemctl），stdout/stderr 实时日志
  • • Web 终端：节点列表点"终端"→ xterm.js 交互 Shell（SSH PTY 转发）
  • • 双通道：终端/推送=SSH 直达 · 启停/心跳=Agent 通道
  • • 客户端对推理机无感：只认 VIP:9000 + 模型名 + X-Session-Id

高级能力 ★ v1.4

  • • 多机并行单模型：Ray 集群 head/worker 编排，跨机 TP/PP，注册为单个逻辑实例（入口=head:8000）
  • • 分布式组整组注册/整组摘除；组内任一节点挂 → 全组下线 + 会话重放迁移
  • • 规则路由：客户端带 type 字段（code/vision/…）→ 规则表直达对应模型；未命中走默认池
  • • 解析顺序：具体 model → type 规则 → 默认池
  • • 约束：跨机 TP 需 ≥10/25GbE；同组节点 GPU 同质

商业化能力 ★ v1.5–1.6 定稿

  • • 多租户隔离：API Key→tenant→节点子池∩模型子集过滤，越权 403；QPS 限流 + token 用量可查可导出（无账单）
  • • API 二次开发（首期两层）：管理 REST API（OpenAPI 3.1+PAT）· Webhook（HMAC 签名）；Transformer/鉴权适配器 v1.2 即插即用
  • • 离线交付：气隙环境可装，四框架镜像 tar 导入即 registry
  • • Web 终端 asciinema 录屏 + 命令黑白名单（商用安全评审）
  • • 技术栈：Python 3.11 全栈 + Vue3/Element Plus + xterm.js + asyncssh + Redis 7
